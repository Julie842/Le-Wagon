# Le-Wagon

Projet Le Wagon : Rock, Paper, Scissors ✂️ 

Ce projet simule une partie rapide entre deux joueurs virtuels (ou joueur contre ordinateur) en générant un choix aléatoire lors du clic sur le bouton de jeu.

🔍 Aperçu du projet :

Le projet affiche une interface claire et épurée comprenant :
Une zone d'affichage pour le Joueur 1 et le Joueur 2 avec des émojis (✊, 🤚, ✌️).
Un message indiquant le résultat (It's a Tie!, Player 1 Wins!, Player 2 Wins!).
Un bouton interactif pour lancer un nouveau tour.

✨ Fonctionnalités :
Génération aléatoire : sélection dynamique des coups pour chaque joueur via Math.random().
Détection automatique du gagnant : comparaison instantanée des combinaisons selon les règles traditionnelles du jeu.
Interface responsive et sobre : style moderne tirant parti de Flexbox et d'une police personnalisée.

🛠️ Technologies utilisées :
HTML5 : structure sémantique de l'application.
CSS3 : Flexbox, typographie personnalisée (@font-face), et effets de survol (hover).
JavaScript (ES6) : Manipulation du DOM, gestionnaires d'événements (addEventListener), et logique du jeu.
